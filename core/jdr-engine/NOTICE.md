# Timbre extension engine

Engine sources, prelude and upstream regression fixtures are adapted from
[Ding-DaoDao/Timbre](https://github.com/Ding-DaoDao/Timbre/tree/main/core/extension-engine).
The upstream repository ships the GNU General Public License version 3 text,
preserved in LICENSE.md. Original package names and source comments are retained.

Flux Player changes include Android 23 compatible Base64/ChaCha20 implementations,
expanded archive size validation, OkHttp 4 compatibility, and the Flux source adapter.

The voicesamples test scripts are upstream test fixtures and are not included
in the APK or installed as user sources.
