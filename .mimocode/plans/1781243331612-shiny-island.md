# FAB 滑到底部渐隐动画

## 需求
云盘浏览页滑到底部时，"新建文件夹" FAB 渐隐消失，避免遮挡内容。

## 当前结构
- FAB 在 `CloudBrowserPanel.kt:276-288`，`Alignment.BottomEnd` + `padding(16.dp)`
- 可滚动列表在 `DirectoryStackContent`（栈式导航）或 `LazyColumn`（扁平列表）
- `LazyListState` 在 `AnimatedContent` 内部创建（第 169 行），无法从外部直接访问

## 实现方案

### 1. 添加滚动状态回调
在 `CloudBrowserPanel` 中添加 `var isNearBottom by remember { mutableStateOf(false) }`

### 2. DirectoryStackContent 检测滚动位置
在 `DirectoryStackContent` 中用 `LaunchedEffect` + `snapshotFlow` 检测：
- `listState.layoutInfo.visibleItemsInfo.lastOrNull()?.index` 接近 `totalItemsCount`
- 调用回调通知父组件

### 3. FAB 渐隐动画
```kotlin
val fabAlpha by animateFloatAsState(
    targetValue = if (isNearBottom) 0f else 1f,
    animationSpec = tween(300)
)
FloatingActionButton(
    modifier = Modifier
        .align(Alignment.BottomEnd)
        .padding(16.dp)
        .alpha(fabAlpha),
    ...
)
```
