# 弹性液态玻璃底栏

## 需求
给底栏添加物理弹簧动画和弹性效果，参考 Legado 的 `FloatingBottomBar`。

## Legado 的核心效果
1. **移动指示器** — 选中项有一个胶囊指示器，切换时用弹簧动画移动
2. **按压缩放** — 按下按钮时指示器放大（1.0→1.2x），释放时回弹
3. **面板偏移** — 拖拽时整个面板有微小弹性偏移
4. **触摸高光** — AGSL shader 触摸高光（需 Android 13+）

## 简化实现方案

### 核心动画
用 `Animatable` + `spring` 实现指示器位置动画，用 `animateFloatAsState` 实现按压缩放。

### 结构
```
Box {
  // 背景层：液态玻璃容器
  Row(drawBackdrop) { 3个按钮 }

  // 指示器层：可移动的液态玻璃胶囊
  Box(drawBackdrop + combinedBackdrop)
    .graphicsLayer { translationX = indicatorOffset }
    .graphicsLayer { scaleX/scaleY = pressScale }
}
```

### 关键代码
```kotlin
val indicatorAnim = remember { Animatable(selectedTab.toFloat()) }
LaunchedEffect(selectedTab) {
    indicatorAnim.animateTo(selectedTab.toFloat(), spring(dampingRatio = 0.6f, stiffness = 400f))
}

val pressScale by animateFloatAsState(
    targetValue = if (isPressed) 1.15f else 1f,
    animationSpec = spring(dampingRatio = 0.5f, stiffness = 300f)
)
```
