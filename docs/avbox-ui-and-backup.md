# AVBox 外观移植与备份修正

## 本地路径

备份与恢复新增“本地备份目录”，通过 Android 系统目录选择器保存长期读写授权。选定后本地导出直接在该目录创建带时间戳与随机标识的普通 ZIP 备份；未选定时保留逐次选择导出文件的方式。新增本地自动备份模式，与 WebDAV 自动备份二选一。

本机目录权限不能随备份转移到其他设备或另一个应用包名。恢复备份设置时保留本机已有授权目录，并关闭自动备份。Android 11 及以上可能不允许选择存储根目录或下载根目录，可以在允许的位置创建备份子文件夹。

## 在线书籍封面

之前在线书籍只有封面 URL，图片未进归档。现在按书源与封面 URL 的稳定标识读取同一份 Coil 缓存；缺图时通过书源解析封面地址和请求头，下载后校验图片。归档新增 listening_covers 图片条目，恢复后写入应用私有封面目录，书籍界面优先读取这些图片，可在无网络、链接失效或书源尚未加载时显示。

本地导出和 WebDAV 上传共用普通 ZIP 归档，不需要密码，也不支持旧加密格式。封面先读取本机恢复图片和磁盘缓存，再尝试书源解析或普通图片地址。书源已禁用、已删除、加载失败、下载失败或图片无效时只影响该封面，其余数据继续导出；完成后明确列出无法取得封面的书名和原因。单图限制为 4 MB，封面合计限制为 24 MB，超过封面限额的图片也作为缺失项提示。整体归档载荷限制为 64 MB。恢复会先校验文件名、大小和图片有效性。旧的非加密备份没有包含图片时仍可读取，但不会凭空生成离线封面。

## 主题与页面

依据本地 AVBox 的 ThemeSettingsPage、PhoneMockupPreview、CapsuleSegmentedButton、ThemeColorPickerSheet、SettingsAppInfoCard 和 Type 移植布局与交互，状态改接 Flux 的偏好存储：

- 手机主题预览、八种预设的小型配色卡、横向九种风格选择。
- 自定义主题开关、纯黑开关、三段明暗模式按钮。
- 色相／饱和度色轮、亮度滑块、初始与当前颜色比较。
- 液态玻璃分组、滑块数值胶囊和重置入口。
- 设置首页的应用信息卡、版本胶囊、紧凑目的地行。
- 主应用字号、行高和字重使用 AVBoxTypography；分组采用 32／4 dp 圆角、2 dp 组内间距与 surfaceBright 卡片底色。

保留 Flux 的功能入口和品牌；视频页保持文件浏览结构，播放器独立界面保留原有布局与排版。

## 手机底栏

移植 FloatingNavBar、DampedDragAnimation、DragGestureInspector 和 InteractiveHighlight 的分层实现：页面背景、独立图标副本、选中透镜各自独立；采用 ContinuousCapsule 连续胶囊、背景调色与模糊、按压折射、图标染色、内阴影、高光和拖动形变。标签仅在选中项显示。

这些消费者位于页面录入区域外。图标副本只读取页面背景，选中透镜读取页面背景及图标副本，录入区域不包含采样自己的控件，避免之前的绘图层循环。ContinuousCapsule 的基类为 CornerBasedShape，符合当前折射库支持的形状类型。

Flux 的底栏仍保留视频、浏览、历史、听书四个实际入口，手机采用横向布局；不新增 AVBox 的电视直播或站点入口。液态玻璃需要 Android 13 及以上，较旧系统使用普通底栏。

输出共存版 com.fluxplayer.app.uipreview，版本后缀 ui-preview3-avbox。本次进行代码执行路径核对、格式整理和编译；遵照用户要求未运行自动化测试或手机交互测试。编译成功不代表手机上的备份权限、书源网络与所有渲染情形均已实测。
