# 六家网盘凭证与多账号第二轮复查

日期：2026-10-24。范围：继续对照本机 wenxi 的登录会话、Vault、多账号页面及恢复流程。以下区分本轮已经修正的遗漏与仍未完成的对齐项；不读取真实账号凭证。

## 本轮确认并修正

| 遗漏 | 处理与验证 |
| --- | --- |
| 移动切换账号后复用同一个客户端，界面记住的扩展功能对象仍绑定原账号 | 换号重建客户端，搜索等扩展对象随客户端更新；增加旧对象拒绝请求、新对象使用所选账号的模拟 HTTP 测试。 |
| 只依赖可见页面响应账号变动，隐藏页面和旧版备份恢复可能漏刷新 | 五个 ViewModel（夸克/UC 共用类型）自行订阅账号修订；重载有幂等判断并在取消旧任务后重建订阅；旧版备份恢复也发布修订。 |
| 只隔离目录及普通直链缓存，画质和 123 HLS 备用缓存仍以平台/文件 ID 区分 | 两类缓存增加账号边界；播放器的兼容扫描也按账号过滤；旧账号播放的画质刷新和备用地址切换不能借用当前账号。增加六家缓存隔离测试。 |
| 123 重登后缺少 wenxi 的服务端身份复核 | 密码登录及自动续期读取用户信息，要求有效 UID；已有 UID 时自动重登必须一致；成功保存 UID，旧备份字段可缺省，首次成功校验后补存。UID 不一致时保留旧 token 并阻断自动重试。 |
| 手动导入 123 token、夸克/UC Cookie 时先覆盖再试用 | 先用候选客户端验证已登录接口，成功后再提交；验证失败保留原凭证，UC TV 也不会因失败候选而清理。增加失败导入及 Cookie 更新隔离测试。 |
| 恢复前只检查外层版本和平台数量，账号名称和字段类型在密钥准备之后才继续校验 | 独立解析完整恢复计划；账号列表、归属、重复字段、类型及秘密字段全部通过后，才允许进入存档、密钥修复和实际写入。 |
| AtomicFile 主文件缺失、仅备用文件存在时，界面错误显示没有恢复副本 | 可用性识别 .bak，读取交由 AtomicFile 恢复；本地及导出数据限制为可重新读取的大小；增加备用文件恢复测试。 |
| 改名、移除非当前账号也会作废当前会话 | 这些元数据改动不再增加当前会话版本，不触发目录重载；增加会话版本保持测试。 |
| 全部账号恢复之后再清全局登录态，可能清掉界面刚恢复的新会话；天翼仍可能指向旧账号配置 | 清理顺序移到恢复发布之前；恢复后重绑天翼配置；增加活动账号与天翼内存凭证一致性测试。 |

源码参考：wenxi `lib/data/providers/token_session.dart`、`lib/data/providers/pan123.dart:_performRenewal`、`lib/data/providers/cookie_cloud.dart:_accept`、`lib/data/state_store.dart:Vault.renameAccount`、`lib/data/state_key.dart`。FluxPlayer 对应改动在 CloudAccountStore、CloudAccountRecovery、两个播放缓存、各 BrowserViewModel、Pan123ApiClient、QuarkApiClient 及 BackupManager。

## 继续对齐之前确认的四项差异（历史记录）

1. **按资源所属账号后台取址和续期。** FluxPlayer 当前主动拒绝用其他账号解析历史文件，要求用户先切账号。wenxi 可以通过账号作用域获取对应凭证。要达到同等行为，还需要把天翼、移动等全局鉴权状态改为按账号管理，并让播放、下载刷新携带明确账号上下文；仅增加账号 ID 或换号校验不等于完成此项。
2. **全部账号恢复的崩溃原子性。** 当前完成完整预校验、原数据存档和异常回滚，但仍逐份写入 SharedPreferences。进程在多份写入中间被杀时，不能保证全部平台同时提交或同时回退。wenxi 的加密状态快照使用统一提交。需要统一快照或可恢复的事务日志，当前不能称为同等保证。
3. **账号管理页面的全部操作。** 当前有添加、切换、改名、重新登录、移除和备份恢复。wenxi `lib/ui/cloud_accounts_page.dart` 另有账号详情、复制登录信息、直接进入指定 UC 账号的 TV 授权等入口。FluxPlayer 尚未全部搬到账号列表；现有 UC TV 入口服务于当前账号。
4. **普通应用备份的整体加密。** 新增的账号密码备份已加密；既有普通 JSON/ZIP 应用备份仍按原产品设计保存解密后的账号字段。wenxi 的整体备份由密码保护。不能将“新增账号密码备份”描述为“所有备份已经对齐”。两项目备份互导也未实现，但这与凭证本身能否保存、恢复是不同事项。

以上四项已在用户要求继续对齐后补齐，具体实现及最新验证见 `wenxi-auth-parity-completion-2026-10-24.md`。下面的验证数量属于第二轮复查时的记录。真实服务在线登录、验证码、续期与播放仍需真实账号验收。

- Compose 界面及搜索、批量操作回归：11 项通过。
- 编译播放器、网盘界面并构建 UI 共存测试包通过。
- 日志：`build/auth-second-audit-validation.log`、`build/auth-second-audit-device-tests.log`、`build/auth-second-audit-ui-tests.log`。
- 测试使用样例凭证及模拟 HTTP，没有访问用户真实网盘账号。
