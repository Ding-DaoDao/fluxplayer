# B站听书 JDR

将 `com.fluxplayer.bilibili-0.1.2.jdr` 导入 Flux Player 的听书源。

- 首页直接显示热门听书书籍；更新后的 App 将分类显示为顶部横向栏，书籍以三列封面展示。
- 支持听书关键词搜索、分类浏览、BV 号或视频链接直达、分 P 目录和独立音轨解析。
- 分 P 按视频原始顺序排列；播放器负责续播、定时和后台播放。
- 配置里的 Cookie 可选。公开视频可尝试免登录，受平台限制的内容需要自己的有效登录态。
- 登录页返回时先验证账号，再保存 Cookie；未完成登录不会覆盖原来的账号配置。失效的凭据会提示重新登录，也可手动填写 Cookie。此版本未实现扫码登录。
- 登录态会用于搜索和音频解析。首页按公开热门搜索排序，不是个性化推荐；尚未同步 B站收藏、关注和观看记录。
- 音频地址按需解析，不持久化短期有效的 CDN 地址。
- 自动线路优先选择普通备用 CDN，再回退主线路，避免部分网络无法连接的 PCDN；配置中也可指定主线路或备用线路。
- 搜索采用 abts 的有声内容筛选；可以在配置中关闭筛选。
- 更新后的 Flux Player 书源页面提供搜索框，搜索与分类结果均可触底加载下一页。旧版 App 需要更新后使用 0.1.2 的分页搜索。
- JDR 搜索可返回旧版数组（单页），也可返回 `{ "items": [...], "totalPages": 3 }`；未提供总页数时可用 `nextPage` 告知下一页。
- B站网络风控、视频下架、权限限制和音轨缺失会返回错误提示，不能保证所有公开视频均可播放。
- 仅将一个视频的分 P 作为章节；此版本不合并合集里不同 BV 的视频。

构建：`python build.py`。测试：`node verify.mjs`，真实网络检查：`node verify.mjs --live BV号`。

移植来源：https://github.com/Ding-DaoDao/abts 。基于其接口逻辑、WBI 签名和有声内容筛选进行 JavaScript 适配；保留 MIT 授权见 LICENSE。
