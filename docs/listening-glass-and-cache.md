# 听书封面缓存容量

## 封面缓存

- 默认磁盘上限由 128 MB 提升到 1 GB。
- 听书缓存设置可选 256 MB、512 MB、1 GB、2 GB、4 GB。
- 容量保存到封面缓存配置，并用于创建实际的 Coil 磁盘缓存。
- 已打开的磁盘缓存保持当前上限，修改后下次启动应用生效。界面区分当前生效容量与待生效容量，避免只修改显示值。
- 不预先占用选定空间，图片按需写入；内存缓存继续保持 32 MB。
- 沿用已有缓存目录与缓存键，避免升级后丢失已有图片。
