# 无密码备份（2026-10-14）

按用户明确要求，本地与在线备份均改为普通 ZIP，不再设置密码，不再加密，也不再读取旧加密备份。

- 手动保存到所选目录和逐次选择文件位置都直接导出。
- WebDAV 手动上传和本地/在线自动备份使用同一个普通 ZIP 编码器。
- 已删除备份密码设置、密码配置字段、恢复密码弹窗、加解密实现及对应的过时测试。
- 旧配置中的密码字段作为未知字段忽略，之后保存配置和生成备份时不再写出。
- 恢复仍支持普通 ZIP 与 JSON，并保留内容选择、归档大小限制、文件名检查和图片校验。不支持的文件格式显示错误，不弹密码框。
- 备份继续包含设置、账号配置、OpenList 数据及在线书籍封面，成功提示保留。
- WebDAV 登录所需的服务器账号密码仍是连接配置的一部分，与已删除的备份密码不同。

共存版版本为 `0.16.4-ui-preview6-avbox`。按用户要求不运行测试，仅检查修改代码并编译。
