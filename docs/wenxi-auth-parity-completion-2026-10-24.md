# 六家网盘登录凭证对齐：剩余四项补齐

日期：2026-10-24。对照项目：`E:/Projects/wenxi`。本轮处理第二次复查留下的四项差异；没有读取用户真实账号。

## 按文件所属账号运行

- `CloudAccountScope` 用协程上下文绑定账号，跨调度线程仍保留资源归属，不修改界面所选账号。
- 六家内存凭证、天翼家庭会话及刷新锁、Cookie、会话版本、播放头注册按账号隔离。CookieJar 显式绑定客户端账号，网络工作线程也不会借用界面账号。
- 播放解析、123 画质刷新及备用地址读取使用文件 URI 的账号；每个媒体数据源携带自己的账号，并行分段请求也继承此绑定。
- 五个浏览 ViewModel（夸克与 UC 共用一个）下载时捕获账号、客户端和文件资料。换号只取消界面任务，保留已经发起的下载；阿里下载历史原有 `aliyun` 来源名称映射回 `alipan` 的账号标识。
- 移除或重新登录会使对应账号的旧会话失效，单纯切换浏览账号不会注销原账号。

## 六家账号恢复统一发布

- 先完整校验导入数据，再为所有账号创建新的凭证配置文件。
- 账号的逻辑 ID 保持不变，列表通过独立的存储版本字段指向新文件，因此历史 URI 不需要变更。
- 只有所有新文件写入成功后，才以一次同步 SharedPreferences 提交发布六家的完整账号列表。发布文件使用 Android 的原子写入机制；分阶段写入期间退出，仍然使用完整的旧账号列表。
- 写入第三份凭证失败的测试验证六家旧配置全部保留。恢复后旧客户端持有的配置文件已经脱离当前列表，继续写入也不能覆盖新凭证。
- 保留恢复前的列表及原凭证文件供上一份列表恢复使用；恢复单个平台只清理该平台内存凭证。
- 此保证针对六家账号配置，普通应用备份中其他模块的恢复仍按原有模块顺序执行。

## 账号界面操作

- 账号行保留登录按钮，更多菜单提供账号详情、复制登录信息、改名、移除；UC 另有 TV 播放授权。
- 详情展示所选账号的登录字段，默认遮盖内容，可逐项显示、复制或复制全部登录信息。点击复制时重新读取该账号，不使用界面当前账号替代；复制范围与 wenxi 相同，不包含登录密码和设备私钥，不记录凭证值。
- UC 授权服务及轮询使用菜单指定账号，不要求先切换浏览账号。
- 既有添加、切换、密码账号备份、本地副本恢复入口保留。

## 普通应用备份整体加密

- 设置页增加备份密码及二次确认，要求至少 8 位。新建本地、WebDAV、自动备份均加密完整归档；没有密码时不会回退为明文备份。
- 完整归档包括应用配置、六家全部账号、旧兼容凭证字段、WebDAV 设置及附带文件，使用 PBKDF2（310000 次）派生 AES-256-GCM 密钥，每份使用独立盐及随机 IV，头部参与完整性校验。
- 本机用于自动备份的密码经 Keystore 加密单独保存，不写入导出的应用配置，也不随系统 SharedPreferences 备份迁移。
- 加密导入先要求备份密码，密码错误可重试；解密后仍需经过原有恢复内容确认。修改本机备份密码只影响之后创建的备份。
- 旧版明文 ZIP 和 JSON 继续可读。FluxPlayer 与 wenxi 的备份格式仍各自独立，没有实现两项目备份文件互导。
