# 当前选书与本地书库索引

## 当前选书

“最近听过”中的在线书籍在播放请求被接受后立即成为当前选择，并显示缓冲状态，不等待媒体服务连接或书源解析。播放服务也优先使用已知书籍快照发布选书状态，随后继续读取完整详情并解析实际音频地址。

旧播放器回调在新书解析期间不覆盖新选择；首页在比较本地、在线会话时优先显示较新的在线缓冲请求，避免仍播放旧本地书籍时显示错误横幅。连接或解析失败保留对应错误，不让缓冲状态一直停留。

书籍详情与书源解析原来共用单线程，读取详情可能排在已有请求之后，因此不能把首页更新放在详情读取完成之后。

## 本地书架

- 选择或重新选择书库目录时生成新的扫描标记，只处理一次该选择。
- 扫描完成后将完整书架、封面引用和章节列表保存到应用私有索引。
- 启动应用和重新进入听书页读取索引，不重新枚举外部目录。
- 新增、删除书籍或章节后，只有用户手动刷新才重新扫描并更新索引。
- 升级时使用已有书籍索引迁移书架，不为了迁移枚举外部目录；不能从旧索引推断书架归属的第三方文档提供器需要手动刷新一次。
- 扫描失败或进程中断后不在下次启动自动重试，用户可手动刷新。

## 在线音频缓存现状

在线播放服务优先查找 `ListeningDownloads` 已完成的章节文件，有文件时播放本地音频，否则使用书源解析出的网络资源。现有手动离线下载会保存文件；ExoPlayer 的播放缓冲位于内存；下一章预解析只提前取得播放资源地址。

在线播放服务尚未接入 `CacheDataSource` 等边播放边写入磁盘的自动缓存。本次没有新增自动音频缓存。封面缓存容量设置与音频下载是独立的。

按用户要求仅做格式与模块编译检查，不生成安装包，不运行测试或设备交互验证。
