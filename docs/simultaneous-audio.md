# 与其他音频同时播放

“设置 → 音频”提供“允许与其他音频同时播放”开关；“设置 → 听书配置 → 播放”通过入口跳转到统一音频设置。

- 开启：视频、本地听书和在线听书不申请音频焦点，允许其他应用的音频继续播放，也不因音频焦点丢失主动暂停。
- 关闭：沿用原来的音频焦点处理，遵循系统的播放互斥规则。
- 沿用持久化的 `PlayerPreferences.requireAudioFocus` 字段，界面显示其反值，默认关闭同时播放。已有偏好和备份保持兼容，无需迁移配置。
- 视频与本地听书的 PlayerService、在线听书的 TingshuPlaybackService 均在启动时读取持久化配置，并在运行期间监听更新。修改开关无需重启；已经暂停的音频不会自动恢复。
- 耳机断开暂停由独立设置控制，视频、本地听书和在线听书均监听该设置；睡眠定时沿用原有暂停逻辑。不同设备或其他应用本身可能限制音频混播。

在线听书通过应用实现的 ListeningAudioPreferencesProvider 读取持久化音频偏好，避免直接依赖数据层。应用显式依赖 core:tingshu 来提供这项接口。

本功能初次修改时完成格式和编译检查；后续设置清理已构建共存测试版，并补充设备回归，详见 [设置清理与行为修复](settings-cleanup.md)。
