# AVBox 设置迁移范围

本轮以本地 AVBox 的 ThemeSettingsPage、PreferenceSettingsPage、PlaySettingsPage 为参考。设置使用 Flux 原有偏好存储与备份模型，播放器页面布局保持不变，视频页恢复直接显示文件夹／文件列表。

| AVBox 项目 | Flux 的落点与实际行为 |
| --- | --- |
| 跟随系统／浅色／深色 | 设置 → 外观；实时切换主应用主题 |
| 系统取色／自定义种子色 | 壁纸动态取色、八种预设、RGB 滑块与十六进制输入 |
| 九种配色风格 | 同版本 Material Kolor 配色引擎；选择风格时切到自定义种子色 |
| 纯黑模式 | 深色时覆盖背景和表面层，保留可读的主题前景色 |
| 底栏／顶栏液态玻璃 | 独立开关；页面背景录入后提供模糊、折射、色散；区域外顶栏使用玻璃；录入区域内的开关和图标不采样自身背景，以避免绘图层循环引用 |
| 模糊／折射／通透度／色散 | 范围分别为 0–40 dp、0–30 dp、0–100%、开关；默认 20／30／50%／开启，可单独恢复 |
| 导航动画与手势 | 底栏拖动、选中态动画、根页面和设置导航转场开关 |
| 隐藏状态栏 | 主应用窗口生效；可从屏幕边缘临时唤出 |
| 历史合并／无痕 | 合并同名记录的显示；视频无痕时停止新增播放历史和视频状态写入，听书独立进度保留 |
| 历史条数 | 50–1000 条的显示上限；原始数据保留，避免升级时删除记录 |
| 网格列数 | 0 为自动，1–6 为指定列数；视频网格和听书首页网格生效 |
| 应用语言 | Android 13 及以上使用系统应用语言选择页，列出仓库实际提供的翻译；新增加的中文设置文案尚未补全其他语言翻译 |
| 启动页／隐藏导航入口 | 复用 Flux 的启动页与视频、浏览、历史、听书入口显示设置 |
| 隧道播放／优先 AAC | 设置 → 播放；接到现有 Media3 轨道选择器，设备支持时生效 |
| 缓冲时长 | 设置 → 播放；10–120 秒，仍受原有 64 MB 缓冲内存上限约束，重启应用后生效 |
| 解码、画面比例、长按倍速、手势 | 保留 Flux 已有解码器优先级、画面缩放、长按速度和手势设置 |
| 弹幕、播放缓存、清理缓存 | 保留 Flux 已有弹幕来源管理、播放缓存容量和清理入口 |
| 音乐／听书页 | 保留 Flux 现有听书页和音频播放器 |

## 未直接移植的独立能力

- IJK、VLC 内核及内核预热、渲染器切换、Anime4K：当前使用 Media3，增加这些选项需要额外引擎和渲染实现。
- 电视直播入口、多线路自动切换、M3U8 净化、多源视频搜索线程：依赖 TVBox 内容源和线路模型，Flux 的文件／网盘／听书来源没有同等数据结构。
- 下一集提前预加载及预加载时长：不等于播放缓冲时长，需要独立的下一集预加载与缓存生命周期管理，本轮未实现。
- AVBox 收藏列数映射为已有媒体网格列数；未新增 AVBox 视频站收藏体系。

## 交付方式

按用户要求仅编译普通 debug APK 并使用 ADB 覆盖安装到连接的手机；不运行自动化测试或人工交互测试，实际显示与播放由用户检查。

新增设置的保存、读取、执行路径与修正项见 [设置生效核对](E:/Projects/fluxplayer/docs/settings-effectiveness-audit.md)。
