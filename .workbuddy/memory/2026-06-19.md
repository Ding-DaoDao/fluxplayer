# 2026-06-19

## 修复：点击视频页文件夹后自动跳转到浏览页

**问题**：在"视频"Tab 点击文件夹后，`rememberSaveable` 初始化的 `selectedTab` 会重置为 `startupPage` 偏好，导致 Tab 自动切换。

**根因**：文件夹点击触发导航 `MediaPickerRoute(folderId)`，创建新 composable 实例，`selectedTab` 重新从 `startupPage` 初始化而未保持原 Tab。

**修复**（方案 A — 路由传递 selectedTab）：
1. `MediaPickerRoute` 数据类新增 `selectedTab: Int? = null` 字段
2. `FolderArgs` 新增 `selectedTab` 字段，从 `SavedStateHandle` 提取
3. `MediaPickerViewModel` 暴露 `routedTab` 属性
4. `navigateToMediaPickerScreen()` 新增 `selectedTab: Int?` 参数
5. `MediaPickerRoute` composable 中 `rememberSaveable` 优先使用 `viewModel.routedTab`，为 null 时回退到 `startupPage`
6. `onFolderClick` 签名改为 `(folderPath: String, selectedTab: Int) -> Unit`，点击时传递当前 Tab 索引

**影响文件**：
- `feature/videopicker/navigation/MediaPickerRoute.kt`
- `feature/videopicker/navigation/MediaPickerNavigation.kt`
- `feature/videopicker/navigation/FolderArgs.kt`
- `feature/videopicker/screens/mediapicker/MediaPickerViewModel.kt`
- `feature/videopicker/screens/mediapicker/MediaPickerScreen.kt`
- `app/navigation/MediaNavGraph.kt`

## 修复：播放界面点击上一集不切换集数

**问题**：播放 > 5s 后点击"上一集"，进度跳到本集开头而非切上一集。

**根因**：`PreviousButton` 使用 Media3 的 `rememberPreviousButtonState`，其默认行为模仿音频"上一首"逻辑：position > 5s → `seekTo(0)` 重播本首；position <= 5s → `seekToPreviousMediaItem()` 切上一首。

**修复**：直接使用 `player.hasPreviousMediaItem()` + `player.seekToPreviousMediaItem()`，移除 `rememberPreviousButtonState` 及其 `@OptIn(UnstableApi)` 注解。

**影响文件**：
- `feature/player/buttons/PreviousButton.kt`
