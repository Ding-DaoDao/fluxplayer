# 2026-06-20

## 天翼云盘 Token 刷新链路 Bug 修复

**文件:** `core/data/src/main/java/com/fluxplayer/app/core/data/cloud189/C189ApiClient.kt`

修复了 4 个导致 token 持久化后不匹配/刷新不完整的 bug：

### Bug 1 & 2（严重）: signedGet/signedPost retry 路径覆盖新 token 为过期值
- **根因:** `login4MergedClient()` 只更新 apiClient 实例字段，不更新 `C189AuthProvider`
- signedGet/signedPost 在 retry 中调用 `login4MergedClient` 后，又从 C189AuthProvider 读取（过期值）覆盖回 apiClient
- **修复:** `login4MergedClient()` 末尾新增同步 C189AuthProvider 逻辑；删除 signedGet/signedPost 中已无必要的覆盖赋值

### Bug 3（中等）: refreshAccessToken() sessionKey 回退路径不刷新 session
- 当 refreshToken 失败、回退到 sessionKey→getAccessTokenBySsKey 时，只更新了 accessToken，未刷新 sessionKey/sessionSecret
- **修复:** 回退路径中新增 `tryRefreshSessionViaAccessToken(newAt)` 调用

### Bug 4（低）: openApiPost retry 缺少 sessionSecret 同步
- openApiPost retry 中只从 C189AuthProvider 同步了 accessToken 和 sessionKey，漏了 sessionSecret
- **修复:** 补齐 `sessionSecret = C189AuthProvider.sessionSecret`

**编译验证:** `./gradlew :core:data:compileDebugKotlin --rerun-tasks` → BUILD SUCCESSFUL
