## 听书章节进度切集不更新 — 修复

**问题**: 切集后详情页始终只在第一集显示进度（如"已听46%"），其他集不显示。

**根因**: `PlayerActivity` 中两处听书进度保存使用 `lifecycleScope.launch`。`finishAndStopPlayerSession` 在协程末尾调用 `finish()`，触发 Activity 生命周期到 DESTROYED 时 `lifecycleScope` 被取消，可能中断正在执行的 DataStore 写入。

**修复**: 
- `finishAndStopPlayerSession()` — DataStore 写入包裹在 `withContext(NonCancellable)` 中，确保即使 `lifecycleScope` 销毁也能完成写入
- `onSaveResume` 回调 — 同样包裹 `NonCancellable`
- 编译验证: `:feature:player:compileDebugKotlin` + `:app:compileDebugKotlin` BUILD SUCCESSFUL

## 听书章节进度始终在第一集 — 根本修复

**问题**: 上一轮 NonCancellable 修复无效，切集后仍然只显示第一集进度（已听46%）。

**深层根因**: `player.currentMediaItemIndex` 在切集过渡期可能返回 `C.INDEX_UNSET`（即 -1）。进度保存时 key=`bookPath|-1`，被 detail 页的 `filterKeys { it >= 0 }` 过滤掉，等于进度被丢弃。仅第一集因初始播放 `currentMediaItemIndex=0` 能正确保存。

**修复策略**: 不再依赖 `currentMediaItemIndex`，改用 `mediaId`（文件绝对路径）反查章节索引：

1. **PlayerActivity** — 新增 `audioBookChapterPaths: List<String>` 字段，在 `playVideo()` 音频路径中缓存所有章节文件的绝对路径
2. **PlayerActivity** — 新增 `resolveChapterIndex(providedIndex)` 方法，用 `mediaId` 在 `audioBookChapterPaths` 中 `indexOf` 反查真实索引，兜底 `providedIndex.coerceAtLeast(0)`
3. **PlayerActivity** — `finishAndStopPlayerSession()` 用 `mediaId + chapterPaths.indexOf()` 计算 `chapterIndex`
4. **PlayerActivity** — `onSaveResume` 回调改用 `resolveChapterIndex(providedIndex)`
5. **AudioPlaybackScreen** — `LaunchedEffect` 中 `idx` 改用 `chapterPaths.indexOf(mediaId)` 计算，不再直接用 `currentMediaItemIndex`
6. **AudioPlaybackScreen** — 新增 `chapterPaths` 参数

编译验证: `:feature:player:compileDebugKotlin` + `:app:compileDebugKotlin` BUILD SUCCESSFUL
